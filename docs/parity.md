# Patch 2 parity and validation

Minecraft Java 1.21.4 remains authoritative. This is a local Studio client;
published authentication, identity linking and external chat are unfinished.

| Feature             | Implementation and remaining discrepancy                                                                                                                                                                                                                                                                                                                                  |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Block sharpness     | 8x nearest-neighbour source enlargement narrows the observed mesh filtering. HUD sampling is unchanged. Normal GPU mipmapping remains; exact Java sampling remains unverified.                                                                                                                                                                                            |
| Typography          | Private vanilla bitmap glyphs, integer scales, shadows and pooled glyph images shared by HUD, inventory, chat, tooltips and death screen. Unsupported Unicode uses a replacement glyph.                                                                                                                                                                                   |
| Local movement      | Fixed-tick walking/sprint/jump, streamed shape collisions, stepping and bounded input replay. This is display prediction, never a client position claim. Special blocks, effects, swimming, elytra and vehicles still need dedicated prediction.                                                                                                                          |
| Reconciliation      | Bridge input acknowledgement is explicitly separate from Minecraft corrections. Small visual errors decay; large errors and forced movement correct. No per-position Minecraft acknowledgement exists.                                                                                                                                                                    |
| Remote entities     | Bounded timed interpolation and short extrapolation, rendering visibility separate from replication. Private common-mob/default-player skins on cuboid models; unsupported types, exact geometry, equipment and animations remain incomplete.                                                                                                                             |
| Inventory           | Actual Mineflayer window slots/cursor, left/right/shift/number clicks, held slot and dropping. Minecraft can replace optimistic client-library inventory state. Advanced drag crafting, creative browser and container-specific progress widgets remain. Block icons use textured ViewportFrames; dropped items use actual Minecraft item metadata and textured geometry. |
| Chat and commands   | Shared Minecraft chat and server command parsing/results, bounded completion requests, no operator grant to Roblox identities. Published external chat is disabled until account mapping and Roblox filtering are configured.                                                                                                                                             |
| Mining/placement    | Reach/occlusion validation, Mineflayer actions, cancellation, crack feedback and received server world updates. Local Mineflayer timer-based air prediction is suppressed for canonical terrain. Placement is accepted only after a server block response.                                                                                                                |
| Combat              | Reach/occlusion validated attack/use requests; damage, pickups and entity AI stay in Minecraft. Mob appearance/animation fidelity remains incomplete.                                                                                                                                                                                                                     |
| Sounds              | Tested Creator Store click, hurt and stone/grass steps plus bundled substitutes. Optional permitted playlists and resumable Open Cloud imports. Roblox requires usable audio asset IDs and permissions; original Minecraft audio is not uploaded or redistributed. Exact Minecraft sound coverage remains unfinished.                                                     |
| Sky                 | Local time extrapolation, square celestial bodies, block clouds, fog and day/night ambient colour. Exact Java sky shading, cloud masks, weather, moon phases and light propagation remain unfinished.                                                                                                                                                                     |
| Common block models | Generic variant/multipart selection, parent model resolution, element/block rotations and face UVs; bounded curated set. UV-lock, rescaled element rotations, biome tint and all materials still need work.                                                                                                                                                               |
| Fluids              | Server source/flowing/falling heights, submerged fill and hidden-face culling. Minecraft generates oceans and applies fluid rules. Flowing slopes, animation and exact underwater presentation remain unfinished.                                                                                                                                                         |
| Visibility          | Conservative frustum/residency toggling and native engine occlusion; no destructive camera-driven streaming. Independent canonical voxel cache, dirty borders and model batches. No claim of a validated custom occlusion system or distant LOD.                                                                                                                          |

Live gameplay fixtures use a dedicated, temporary local operator to prepare an
isolated high-altitude test platform. Roblox stays unprivileged. The test account
is deopped after use and the prior operator list is restored. Fixture operations
are development-only; they do not add public gateway console access.

Do not declare full Patch 2 parity from compilation alone. Dated records in
`docs/measurements` describe which live tests and measurements actually ran.

Chat uses fitted per-message backgrounds. /names display|username switches Roblox aliases. Engine-supplied Player.Name becomes the protocol username; longer names use a stable 16-character shortened form. Native Java chat retains its protocol username.

Network failures freeze stale prediction and back off; expired sessions restart with fresh epochs. Terrain processing errors are isolated from gameplay retries. The launcher retains private loopback settings and reuses its managed Studio window. GPU allocation failure caps visibly incomplete previews to 16 faces per partition and retries after a delay.

See [audio](audio.md) and [water](water.md) for remaining coverage gaps.
